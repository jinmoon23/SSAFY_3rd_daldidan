## 3. 핵심 기술 분석

### 3-1. 온디바이스 실시간 객체 탐지

| 항목 | 세부 내용 |
|------|-----------|
| **모델** | EfficientDet-lite0 (양자화 TFLite) |
| **로딩** | `react-native-fast-tflite` + GPU delegate |
| **프레임 처리** | `useFrameProcessor` (15프레임당 1회 샘플링) |
| **전처리** | 중앙 크롭 → 320×320 리사이즈 → RGB uint8 |
| **후처리** | NMS (IoU=0.4) + class_id=52 필터링 |
| **좌표 변환** | 정규화 좌표 → 1080px 크롭 기준 → 절대 좌표 |
| **실행 환경** | React Native Worklet (UI 스레드 분리) |

### 3-2. 서버사이드 당도 예측 모델

| 항목 | 세부 내용 |
|------|-----------|
| **탐지 모델** | YOLOv8l-seg (COCO 사전학습, PyTorch) |
| **세그멘테이션** | Polygon mask 추출 → 배경 제거 후 Crop |
| **특징 추출** | EfficientNet-B0 (1280차원) + 수작업 특징 (6차원) |
| **수작업 특징** | RGB 평균, YCbCr 변환, GLCM 텍스처 |
| **회귀 모델** | MLP (1286→128→1), End-to-End Fine-tuning |
| **실험 모델** | 총 12종 (CNN, LightGBM, XGBoost 조합 비교 실험) |
| **최종 선택** | `cnn_feature_maskcrop_seg` |

### 3-3. 프론트엔드 시각화

| 항목 | 세부 내용 |
|------|-----------|
| **세그멘테이션 렌더링** | Skia Canvas + Catmull-Rom Spline + 포인트 보간 |
| **좌표 변환** | 90° 회전 보정 (landscape→portrait) + 스케일+오프셋 |
| **마스크 효과** | 반투명 오버레이 + Clear BlendMode (하이라이트) |
| **인터랙션** | 터치→주스 애니메이션, 흔들기→리셋, TOP3 필터 |
| **애니메이션** | Lottie (탭 가이드), Reanimated (펄스), Sound (카운트다운) |

## 7. 설계 패턴 및 아키텍처 특징

### 7-1. 디스패처/레지스트리 패턴 (AI 모델 관리)

```
 predict_service.py                    detect_service.py
 ┌───────────────────────┐            ┌───────────────────────┐
 │  predict(model_name)  │            │  register_model()     │
 │  ────────────────     │            │  detect(name, ver)    │
 │  if "cnn_maskcrop":   │            │  ────────────────     │
 │    → import & run     │            │  model_registry{}     │
 │  if "xgb_bbox":       │            │    key → predictor    │
 │    → import & run     │            │  ┌─────────────────┐  │
 │  if "lgbm_seg":       │            │  │ yolov8:l → cls  │  │
 │    → import & run     │            │  │ yolov8_pt:l     │  │
 │  ...                  │            │  │ ...             │  │
 │  (12개 모델 분기)      │            │  └─────────────────┘  │
 └───────────────────────┘            └───────────────────────┘

 특징:
  • Lazy Import: 선택된 모델만 메모리에 로드
  • 모델 교체 시 상수 1줄 변경으로 전환 가능
  • 12개 실험 모델 병행 운영 → A/B 테스트 가능
```

### 7-2. Custom Hook 기반 관심사 분리 (Frontend)

```
 ┌─────────────────────────────────────────────────────────────┐
 │                    Hooks 계층 구조                            │
 │                                                             │
 │  useObjectDetection ───→ 온디바이스 TFLite 추론 + 좌표 관리 │
 │       └── useImageProcessing ───→ Worklet 프레임 전처리     │
 │                                                             │
 │  useAnalysisApiHandler ───→ API 호출 상태 관리 (FSM)        │
 │       └── useObjectAnalysis ───→ fetch API 통신 전담        │
 │                                                             │
 │  useShake ───→ 가속도 센서 기반 제스처 인식                   │
 │                                                             │
 │  • 각 Hook은 단일 책임 원칙 준수                             │
 │  • 상태 로직과 UI 로직 완전 분리                             │
 │  • Worklet 기반 고성능 프레임 처리 (UI 스레드 비차단)         │
 └─────────────────────────────────────────────────────────────┘
```

### 7-3. 좌표 변환 파이프라인

```
 원본 이미지 좌표 (Landscape, 예: 4032×3024)
       │
       │ ① 시계방향 90° 회전
       │    rotatedX = originalH - originalY
       │    rotatedY = originalX
       ▼
 회전된 이미지 좌표 (Portrait, 예: 3024×4032)
       │
       │ ② scale = screenH / rotatedH
       │    offsetX = (screenW - rotatedW×scale) / 2
       ▼
 화면 좌표 (예: 360×780)
       │
       │ ③ Catmull-Rom 스플라인 보간 → 부드러운 폴리곤
       ▼
 Skia Path 렌더링
```
